2. Dados tratados

O sistema pode tratar os seguintes dados, inseridos por usuários autorizados:

  • dados de acesso: nome, e-mail, perfil de acesso e senha protegida por hash;
  • dados de clientes: nome, CPF/CNPJ, telefone, e-mail e endereço;
  • dados operacionais: serviços, ordens de serviço, observações e registros de ferramentas;
  • dados financeiros inseridos no módulo de controle financeiro;
  • dados técnicos necessários à sessão segura, como cookies de autenticação.

3. Finalidade e acesso

Os dados são usados exclusivamente para a operação interna do Smartec Gestão, controle de atendimentos, gestão de clientes, serviços, ferramentas e informações financeiras. O acesso é limitado a usuários autorizados conforme seu perfil.

4. Armazenamento e segurança

Os dados são armazenados em banco de dados hospedado na infraestrutura contratada para o sistema. A comunicação com o sistema utiliza HTTPS. São aplicadas medidas como autenticação por senha, controle de perfis, cookies de sessão protegidos e proteções contra ações não autorizadas.

Não vendemos dados pessoais e não utilizamos os dados para publicidade comportamental. Dados podem ser tratados por fornecedores essenciais de infraestrutura, exclusivamente para hospedar e manter o sistema.

5. Retenção

Os dados são mantidos enquanto forem necessários à finalidade operacional do sistema ou ao cumprimento de obrigações legais. Quando não forem mais necessários, serão eliminados ou anonimizados de forma segura, salvo quando a guarda for exigida por lei.

6. Exclusão de conta e dados

Para solicitar a exclusão de uma conta ou de dados pessoais, envie um e-mail para Smartec.juara@gmail.com com o assunto “Solicitação de exclusão de conta - Smartec”. A solicitação será confirmada antes da exclusão e os dados vinculados serão removidos, exceto informações cuja retenção seja necessária por obrigação legal.

7. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no sistema ou na legislação. A versão vigente permanecerá disponível nesta página.
